Документация проекта Redline — Вечный сервер Minecraft

1. Общая концепция

Redline — это ванильный Minecraft-сервер, ориентированный на долгосрочное выживание и сохранение наследия игроков.

Слоган: Redline — вечный сервер.

Главная ценность: Стабильность. Игрок должен быть уверен, что его постройки будут существовать годами без угрозы вайпа или удаления за неактивность.

Целевая аудитория: Взрослые и сознательные игроки, ценящие созидание и историю.

2. Дизайн и визуальный стиль

Сайт должен выглядеть современно и технологично, подчеркивая надежность проекта.

Визуальные элементы:

Цветовая палитра:

Темная тема (основная): Глубокий черный/антрацит с ярко-красными акцентами.

Светлая тема: Чистый белый с мягкими серыми тенями и алыми деталями.

Фоновая анимация: Плавные красные диагональные линии, движущиеся на заднем плане, создающие эффект "энергетического потока" или "красной линии" времени.

Типографика: Гротескные шрифты (без засечек), такие как Inter или Roboto, для легкой читаемости.

3. Функциональные возможности

Главная страница (Landing):

Индикатор статуса сервера (онлайн, количество игроков) через mcstatus.

Блок о философии "Вечного сервера".

Кнопка быстрого копирования IP-адреса.

Динамическая карта: Интеграция BlueMap (фрейм или ссылка).

Система тем: Переключатель Light/Dark mode с сохранением в localStorage.

Статистика: Вывод данных о самых преданных игроках (время в игре, дата первого захода).

Сообщество: Интеграция с Discord.

4. Техническое задание (ТЗ)

Технологический стек:

Бэкенд: Python / Flask.

База данных: SQLAlchemy (SQLite/PostgreSQL).

Фронтенд: HTML5, CSS3 (переменные для тем), Vanilla JavaScript.

Интеграции: BlueMap API, Minecraft Server Ping.

Структура базы данных (SQLAlchemy):

User:

id (Integer, PK)

username (String, уникальный)

uuid (String, уникальный)

first_join (DateTime)

last_seen (DateTime)

playtime (Integer, минуты)

Settings: (Для хранения глобальных настроек сайта, если нужно).

Основные роуты (Routes):

/ — Главная страница.

/map — Страница с BlueMap.

/stats — Таблица лидеров и статистика.

/api/status — Эндпоинт для получения текущего онлайна.

5. План реализации

Этап 1: Архитектура (Backend)

Настройка Flask-окружения.

Написание моделей SQLAlchemy.

Настройка логики опроса Minecraft-сервера для получения статуса.

Этап 2: Интерфейс (Frontend)

Создание базового шаблона base.html.

Реализация CSS-анимации красных диагональных полос.

Разработка системы смены тем (Dark/Light).

Этап 3: Наполнение и интеграция

Настройка отображения BlueMap.

Вывод статистики из БД на страницу.

Финальное тестирование адаптивности под мобильные устройства.

6. Требования к хостингу

Наличие Python 3.9+.

Возможность установки зависимостей через pip.

Доступ к портам сервера Minecraft для получения статуса (Query).
