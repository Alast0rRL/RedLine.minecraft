План разработки сайта Redline (Minecraft Server)

Этот план разбит на 5 этапов. Ориентировочное время реализации базовой версии: 7–14 дней.

Этап 1: Подготовка фундамента (Backend)

Цель: Запустить рабочее приложение FastAPI с подключенной базой данных.

Инициализация проекта:

Создание виртуального окружения (venv).

Установка зависимостей (FastAPI, SQLAlchemy, mcstatus, Uvicorn).

Настройка базовой структуры папок (static/, templates/).

Работа с данными (SQLAlchemy):

Создание файла models.py.

Реализация модели User для хранения статистики игроков.

Первичная миграция (создание файла БД redline.db).

Логика сервера:

Написание функции для пинга Minecraft-сервера через mcstatus.

Создание маршрута /api/status для передачи данных об онлайне на фронтенд.

Этап 2: Визуальный каркас и Стили (Frontend)

Цель: Создать интерфейс с "живым" фоном и поддержкой двух тем.

Базовый шаблон (base.html):

Верстка шапки (логотип, навигация, переключатель тем).

Верстка подвала (ссылки на Discord, копирайт).

Система тем (CSS/JS):

Определение CSS-переменных для :root и [data-theme="dark"].

Написание JS-скрипта для переключения и сохранения темы в localStorage.

Анимированный фон:

Создание контейнера для диагональных полос.

Настройка CSS-анимации keyframes для плавного движения линий.

Этап 3: Основные страницы

Цель: Наполнить сайт контентом и функционалом.

Главная страница (index.html):

Hero-секция: слоган "Вечный сервер", кнопка "Копировать IP".

Информационные блоки: "Почему без вайпов?", "Наше сообщество".

Скрипт для динамического обновления онлайна без перезагрузки страницы.

Страница статистики (stats.html):

Вывод таблицы лидеров (Топ по времени в игре).

Форматирование даты первого захода.

Страница карты (map.html):

Интеграция BlueMap через <iframe>.

Кнопка развертывания на весь экран.

Этап 4: Интеграции и Сообщество

Цель: Связать сайт с внешними сервисами.

Discord:

Настройка виджета (инвайт-ссылка, количество участников).

(Опционально) Авторизация через Discord API для личного кабинета.

BlueMap Sync:

Настройка ссылок на конкретные координаты (если нужно).

Этап 5: Деплой и Запуск

Цель: Вывод сайта в онлайн.

Оптимизация:

Проверка скорости загрузки.

Тестирование адаптивности на смартфонах и планшетах.

Развертывание:

Выбор хостинга (VDS или Python-хостинг).

Настройка WSGI-сервера (Gunicorn/UWSGI) - *Note: Uvicorn for FastAPI*.

Настройка SSL-сертификата (HTTPS).

Чек-лист готовности к запуску:

[ ] Кнопка "Копировать IP" работает.

[ ] Тема сохраняется при перезагрузке страницы.

[ ] Линии фона двигаются плавно (без рывков).

[ ] Статус сервера обновляется автоматически.

[ ] Страница статистики не пустая (есть тестовые данные).
